# ห้องซ้อมน้องโดะ

เว็บแอปไฟล์เดียว (`index.html`) สำหรับช่วยเด็กฝึกเปียโน ประกอบด้วย
แผนซ้อม 4 ช่วงพร้อมจับเวลา, เกมอ่านโน้ตบนแป้นเปียโน, สมุดสติกเกอร์,
สรุปการซ้อมรายสัปดาห์, ส่งคลิปให้ครู และโหมดครู (ดูห้องเรียน/ลงคลิปตัวอย่าง)

## ความต้องการของระบบ

- ฟีเจอร์ฝั่งครู (ห้องเรียน, คลิปครู) ต้องรันบน **claude.ai artifact runtime**
  เพราะใช้ `window.claude.use('db')` เป็นฐานข้อมูลคลาวด์ (คอลเลกชัน
  `students` / `lessons`) และ `window.claude.use('assets')` สำหรับอัปโหลดคลิป
- นอก claude.ai แอปยังใช้งานได้ปกติ แต่จะ **fallback เก็บข้อมูลไว้ใน
  localStorage** ของเบราว์เซอร์ (คีย์ `piano-jid-v2`) และการอัปโหลดคลิปจะใช้ไม่ได้
